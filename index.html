How to use Material Scanner.

Scan material in or out

  1. On Scan, pick Check in (arriving) or Check out (leaving).
  2. Press Start camera and point it at the barcode. If it won't read, type the code and press Find.
  3. Set the quantity, add the job or reason, then press the big button.
  4. A banner shows the new stock level. Press Undo if you slipped.

Made a mistake?

You can undo your own scan for 15 minutes from the banner or from History. After that, ask an admin.

Code not found

A short form appears so you can add the material on the spot, then carry on scanning.

Cycle counts

Counts tab: pick materials, count what's on the shelf (expected numbers stay hidden), send for approval. An admin approves differences.

For admins

Stock tab: add, edit, correct counts, delete, export, or import a CSV. Team tab: add other admins.
